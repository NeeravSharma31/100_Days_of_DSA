## 🛠️ How to Compile & Run

### C Programs
Compile using GCC and run the binary:
```bash
# Compile
gcc Day_01/D1Q1.c -o Day_01/D1Q1

# Run (Windows PowerShell / Command Prompt)
.\Day_01\D1Q1.exe

# Run (Linux / macOS)
./Day_01/D1Q1
```

### Java Programs
Compile using `javac` and run with `java`:
```bash
# Compile
javac Day_01/D1Q2.java

# Run
java -cp Day_01 D1Q2
```
